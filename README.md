# kalah-lite 卡拉哈

极简 Kalah（播棋家族）引擎：2×6 坑 + 2 计分仓，播种、进仓再走、吃子、终局扫子。纯 Python 标准库。

## 玩法

- 开局每坑 4 子，共 48 子。
- 从自己一侧任一非空坑抓子，逆时针逐坑播一子；经过**自己**的计分仓放一子，**跳过对方**的计分仓。
- 最后一子落入自己的计分仓 → **再走一步**。
- 最后一子落入自己一侧的**空坑**，且对面坑有子 → 吃掉对面全部 + 本坑这 1 子进仓。
- 一方六坑全空 → 终局：另一方把自己一侧剩余子全扫入仓，仓中子多者胜。

## 用法

```bash
python3 -m kalah_lite            # 人机对战（你是南方）
python3 -m kalah_lite --auto --games 10 --seed 42   # AI 对 AI 演示
```

## 诚实局限

- AI 只是 1 步贪心（再走一步 > 吃子 > 仓子数），不做深层搜索；熟悉规则的人类通常能赢。
- 贪心对贪心时先手优势明显（seed 42 实测 10:0）；随机对随机 20 局 10:9:1，规则本身基本平衡。
- 只有标准 6-6 规则，无变体（如空坑吃子是否需要对面有子等各地差异）。
- 文本界面，无图形/存档/悔棋；Python 3.10+。
